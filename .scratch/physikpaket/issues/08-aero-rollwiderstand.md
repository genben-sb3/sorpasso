# 08: Aero und Rollwiderstand

**What to build:** Luftwiderstand, Abtrieb pro Achse (an der Achsposition angreifend) und Rollwiderstand pro Rad abhängig von der Radlast. Damit bekommt das Auto eine Höchstgeschwindigkeit und eine plausible Ausrollkurve. Das Sportcoupé bekommt seine Aero-Werte.

**Blocked by:** 06

**Status:** done

- [ ] Ohne Gas und Bremse rollt das Auto plausibel aus.
- [ ] Abtrieb erhöht mit steigender Geschwindigkeit die Radlast an der jeweiligen Achse.
